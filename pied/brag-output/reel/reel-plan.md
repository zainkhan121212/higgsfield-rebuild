# Pied — feature reel (Remotion)

Made with **Remotion** (React video) following the rules of two Claude motion-design skills: Remotion's official Agent Skills ([remotion-dev/skills](https://github.com/remotion-dev/skills)) and the community *remotion-motion-graphics* skill ([haidrrrry/claude-remotion-skill](https://github.com/haidrrrry/claude-remotion-skill)): springs and eased curves only, staggered entrances, faster exits, a five-layer stack (background mesh → footage → type → grade → grain + vignette), one hero colour, holds between hits, render → inspect frames → fix.

Vertical 1080×1920 · 30 fps · 39.4 s · soundtrack composed for the cut.

All footage is the real app: screen recordings of the running site (typing a prompt and FLUX painting it, drawing, setting type, painting, the Desktop Studio) and frames from Pied's own engine.
