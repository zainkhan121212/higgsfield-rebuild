I think it's a good idea, stronger than the clone. The clone shows you can copy a site; this shows your own design and a real technical idea, the words *are* the picture. So I built it: it's called **Pied**. In old printing, "pie" means type that got spilled and mixed up. It's pushed to `claude/text-scatter-generator-9hz4te`, in its own folder `pied/`, and your Higgsfield clone isn't touched.

**What it does**
- **Source:** the user writes a prompt, uploads a photo, pastes one, or picks a sample. Uploaded photos stay in the browser and are never sent anywhere.
- **Set:** the picture turns into thousands of letters, using the user's own words or a light-to-dark character set. They can change the font, detail, desktop/phone/square shape, black-and-white or colour ink, light or dark paper, contrast, and how strongly the letters react to the cursor.
- **Paint:** brush, spray paint, eraser and restore, with size, strength, colours, undo/redo and keyboard shortcuts. Painting on empty paper adds new letters there.
- **Keep:** four downloads:
  - a **live wallpaper** (one small HTML file that still scatters under the cursor)
  - a **wallpaper kit** (.zip) for wallpaper apps
  - a PNG image
  - a 7-second video

**Design:** strictly black and white, with a vintage print-shop feel: Caslon and Courier fonts, paper grain, numbered sections. The scroll animations:
- the hero picture falls apart as you scroll down
- a dictionary definition of "pie" darkens in word by word
- a word ticker speeds up and leans with your scrolling
- a four-step "how it works" section changes one picture as you scroll
- the closing headline's letters get pushed around by the cursor

**What I found on the desktop wallpaper question**
- **Windows:** this works properly. Lively Wallpaper (free) and Wallpaper Engine (paid, on Steam) can run a web page as the wallpaper and pass the mouse to it. The kit includes the files both apps look for.
- **Mac:** you'll hit a real limit. macOS never sends the cursor to the desktop. With Plash (free) the letters only react in its "Browsing Mode", which blocks clicking your desktop icons. The site says this plainly.
- **Anywhere:** open the HTML file in a browser and go full screen.

**What I tested:** it builds and lints cleanly. In a headless browser I scripted painting with all three tools, a prompt-to-picture run, every download, and mobile layouts, with no errors. The ZIP opens as a valid archive. The wallpaper file, opened straight from disk, scattered under the mouse. I could not test inside Lively, Wallpaper Engine or Plash, because this environment can't run them. Try the kit on a Windows PC before you demo it.

**Two things before you submit**
- Prompt-to-picture currently uses Pollinations, a free image service that needs no key. It's slow, has usage limits, and adds a watermark that I crop off. If you set `FAL_KEY` (the fal.ai key the Higgsfield clone already uses), it switches to fal, which is faster and has no watermark.
- To deploy on Vercel, import the repo and set Root Directory to `pied`. To run it locally: `cd pied && npm install && npm run dev`, then open http://localhost:3100.

The research notes and technical details are in `pied/README.md`. I haven't opened a pull request; say if you want one.
